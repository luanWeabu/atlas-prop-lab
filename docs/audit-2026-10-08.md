- Browser I2C SDA/SCL order contradicted Guardian firmware. Standardize SDA=8, SCL=9, keeping GPIO19/20 available for USB.
- Update Guardian firmware, Wokwi wiring and electronics documentation together. Keep classic ESP32 bench firmware and its guide unchanged.

- Add regression checks for S3 GPIO validity, pin collisions and firmware/circuit agreement.
